使用场景

日常访问与办公

云画机场适合查阅公开资料、远程会议备份链路、跨境协作文档。基础版的三设备额度可覆盖电脑与手机同时在线；若会议与大文件并行，建议观察流量消耗后升级到旗舰版。

流媒体与内容站

基础版提供基础流媒体解锁；需要全节点原生解锁时选择旗舰版或团队版，降低因公共出口被识别而导致的播放失败。实际效果仍取决于节目版权区域与客户端分流规则。

游戏与低时延

旗舰版写明 IPLC 专线游戏加速优化，适合对延迟波动敏感的对战与更新下载。团队版在高带宽 VIP 节点上可把游戏、语音与下载拆到不同路由，减少互相抢占。

家庭或多成员共用时，用团队版 20 台设备额度统一订阅，比多开个人套餐更易管理流量账单。

客户端下载与官方入口

操作说明

  1. 打开云画官网套餐对比，按流量、设备数与是否需要 IPLC 或定制路由选择基础版、旗舰版或团队版。
  2. 完成开通后在用户中心复制机场订阅链接，妥善保存，不要把订阅公开到群组或截图。
  3. 前往客户端下载分区，安装与系统匹配的兼容客户端，不要混用多个 Tun 内核。
  4. 在客户端选择订阅导入或扫码，手动更新节点列表，等待延迟测试结束。
  5. 按场景选节点：网页浏览用普通线路，流媒体选解锁标识节点，游戏选旗舰版 IPLC 优化线路。
  6. 若设备超限，先在已登录设备中断开，再在新设备连接；团队版可申请定制路由把办公网段直连。

节点与性能说明

云画节点按套餐分层：基础版进入普通线路池；旗舰版增加游戏向 IPLC；团队版提供 VIP 高带宽出口。延迟随当地网络与时段变化，连接后以客户端测速与实际业务为准。流量按自然月或套餐周期累计，超限后应暂停大文件或升级档位，而不是频繁切换非法第三方订阅。

常见问题

云画是机场还是 VPN？和客户端是什么关系？

云画同时以云画机场与云画 VPN 的方式说明同一服务：官网出售订阅，节点由云画维护，你在自己的客户端里导入订阅即可加速。它不是浏览器插件式的一次性代理，而是可更新的节点列表。

如何完成云画官方下载并导入订阅？

先在本页客户端下载分区查看对应系统说明，安装兼容客户端，再把用户中心的订阅 URL 粘贴到「从 URL 更新」。导入成功后更新一次节点，选择代理模式即可。若列表为空，检查链接是否完整、是否被即时通讯软件自动加空格。

三个套餐该怎么选？年付和月付有何不同？

轻度浏览选基础版（100GB / 3 设备）。需要原生流媒体、游戏 IPLC 与优先工单选旗舰版。多人共用、要 VIP 带宽或企业定制路由选团队版。年付金额为基础月价的十倍，适合确定会长用的用户；短期试用可走月付。

云画能否稳定解锁流媒体？游戏延迟如何？

基础版仅承诺基础流媒体；旗舰版与团队版写明全节点原生解锁，但仍受版权地区与 DNS 分流影响。游戏方面，旗舰版提供 IPLC 专线优化，团队版可用 VIP 高带宽减少更新抢占。请以实际对局和播放缓冲为准，不要把一次测速当作长期保证。

流量如何计算？用尽或设备超限怎么办？

套餐按周期提供 100GB、300GB 或 1000GB 极速流量，仅统计代理出口流量。接近用尽时应减少大更新或升级档位。同时在线超过 3/5/20 台时，新设备会连接失败，断开空闲终端即可。团队版可联系客户经理调整路由策略。

工单、客户经理与官方身份如何识别？

旗舰版含 7x24 优先工单，团队版另配专属客户经理。请只通过云画官网公布的下载锚点与工单入口沟通，不要轻信代充或索要订阅截图的第三方。本页不展示用户评分或评论列表，权益以套餐条文为准。
